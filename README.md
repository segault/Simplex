TERMINAL INSTRUCTIONS

First, clone this repository to your local machine using the following command:

```bash
git clone git@github.com:segault/Simplex.git
```

It's gonna prompt you for your github password. Then, go to the project directory:

```bash
cd Simplex
```

and herein will be available to you the main file simplex.py.
You can edit that file directly, or do your work in a separate file, it doesn't
really matter.

When you make a change, do

```bash
git add .
git commit -m "Your commit message"
git push
```

What this does is it adds all the changes you did and then sends them
over to this repository. The commit message is just useful to tell us
what you did.

You will need to update the code that is on your computer with the code that
is in this repository (like any chances that Aidan might have made, Kobe
will need on his computer). To do that, you can run the following command:

```bash
git pull
```
